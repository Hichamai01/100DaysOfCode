### Today's Learning Summary:
* **Distinction between Data and Code:** Understanding that Data is the raw information, while Code is the logic/engine that manages and processes it.
* **Basic Data Types:** Identifying core types including Numbers (Num), Texts (String), and Logical values (Boolean).
* **Variables and Memory:** Conceptualizing variables as pointers that identify specific locations in memory rather than containers that hold data themselves.
* **Data Operations:** Learning how programs store data in memory to perform essential operations such as adding, editing, and deleting information.
