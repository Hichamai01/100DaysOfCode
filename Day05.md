## 📝 What I Learned Todadataday's session focused on the cocodeogic of how computers handle information behind the scenes.
### 1. Data vs. Code: The Engine and the Fuel
 * **Data** is the raw information being managed, such as teacher names or school records.
 * **Code** is the logic or "engine" that performs operations on that data, like calculating monthly salaries.
### 2. Understanding Data Types
 * **String:** Used for names and text-based information.
 * **Num:** Used for numerical values and calculations.
 * **Boolean:** Logical values representing True or False (e.g., whether a teacher attended or not).
### 3. The Variable: A Pointer to Memory
 * A **Variable** does not actually contain the data; it acts as a **Pointer** that identifies the specific location (Address) in the **Memory** where the data is stored.
 * This mechanism allows the code to easily access, retrieve, and modify data stored in the RAM.
### 4. Data Operations
 * Once data is identified by a variable in memory, the code can perform various operations such as adding new records, editing existing information, or deleting data.
