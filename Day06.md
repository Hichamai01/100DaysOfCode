📝 What I Learned Today

Today's session focused on understanding Comments in Python and how they help developers write cleaner and more understandable code.

1. What is a Comment?

- A Comment is a line of text written inside the code for explanation or notes.
- Python ignores comments during program execution.

2. How to Write a Comment

- In Python, comments are written using the "#" symbol before the text.

Example:

# This is a comment

3. Inline Comments

- Comments can also be written beside a line of code to explain what it does.

Example:

print("Hello Hicham") # this is comment

4. Why Comments Matter

- Make the code easier to understand
- Help organize projects
- Allow developers to leave useful notes
- Improve teamwork and code readability

5. Important Note

- Comments do not appear after running the program because Python completely ignores them during execution.
